# مواصفات شخصية «الشايب» لمفاتيح

هذي المواصفات اللي تحتاجها اللعبة عشان تركّب الشخصية مباشرة بدون تعديل. البنود اللي مكتوب جنبها **(إلزامي)** لازم تلتزم فيها، والباقي يحسّن النتيجة.

---

## ١. الملف

| البند | المطلوب |
|---|---|
| **الصيغة** | ملف **GLB** واحد (glTF ثنائي)، والخامات **داخل الملف** **(إلزامي)** |
| **اسم الملف** | `shaib.glb` |
| **الطول** | **١٫٧٠ متر** تقريباً بالحجم الحقيقي **(إلزامي)** |
| **نقطة الأصل** | بين القدمين على الأرض: `(0, 0, 0)` **(إلزامي)** |
| **الاتجاه** | الوجه لقدام على محور **‎-Y في Blender**، يعني ‎+Z في glTF، وهذا الافتراضي في التصدير **(إلزامي)** |
| **الوقفة الأساسية** | وقفة A أو T، والذراعين بعيد عن الجسم |
| **تطبيق التحويلات** | Apply Scale وRotation قبل التصدير (المقياس = 1) **(إلزامي)** |

## ٢. الثقل (عشان يشتغل زين على الكويست)

| البند | الحد |
|---|---|

## ٣. القطع وأسماؤها

خلّ كل قطعة **Mesh مستقل بهالأسماء بالضبط**، عشان اللعبة تقدر تغيّر اللبس أو تخفي القطعة:

| الاسم | القطعة | ملاحظة |
|---|---|---|
| `Body` | الجسم والوجه والأيدي والرجلين | |
| `Thobe` | الثوب | |
| `Shemagh` | الشماغ مع العقال، أو العقال لحاله باسم `Agal` | خامة الشماغ لها مادة اسمها يبدأ بـ `shemagh` |
| `Cane` | العصا | مربوطة بعظمة اليد اليمين |
| `Bisht` | البشت (اختياري، مخفي افتراضياً) | |
| `Glasses` | النظارة (اختياري) | |
| `Misbaha` | المسبحة (اختياري) | مربوطة باليد اليسار |

**أسماء المواد اللي تستخدمها خزانة الملابس:**
- `thobe`: الثوب، وتتغير لونه للبيج أو الرمادي.
- `shemagh…`: الشماغ، ويتبدل بالغترة البيضاء.
- `agal`: العقال، ويتبدل بالعقال المقصّب.

## ٤. الهيكل (Rig)

- **هيكل بشري عادي.** هيكل **Mixamo** يمشي تماماً، ونفس أسماء عظامه مقبولة.
- **عدد العظام:** **٨٠ عظمة** أو أقل.
- **التأثيرات:** **٤** تأثيرات عظام كحد أقصى لكل نقطة (Vertex).
- **عظام إضافية تساعد اللعبة (اختيارية لكن مفيدة):**

| العظمة | مكانها | فايدتها |
|---|---|---|
| `Perch` | فوق الكتف اليسار | مكان وقوف الصقر شاهين |
| `CarrySocket` | قدام الصدر بين اليدين | مكان الأغراض اللي يشيلها |
| `Cane` | داخل قبضة اليد اليمين | مكان العصا |
| `Shemagh.L`, `Shemagh.R`, `Shemagh.B` | أطراف الشماغ يمين ويسار وورا | اللعبة تحركها مع المشي والريح |
| `Skirt.F`, `Skirt.B`, `Skirt.L`, `Skirt.R` | أسفل الثوب من الجهات الأربع | اللعبة تحركها مع المشي |

لو ما سويت عظام الشماغ والثوب، تقدر تحط حركة القماش داخل الحركات نفسها.

## ٦. الحركات

**قواعد عامة:**
- **أسماء الحركات بالضبط** مثل الجدول (حروف صغيرة) **(إلزامي)**.
- **في مكانها (In Place):** يمشي بدون ما يتحرك من نقطة الأصل، واللعبة هي اللي تحركه **(إلزامي)**. في Mixamo فعّل خيار In Place.
- **السرعة:** 30 إطار بالثانية.
- **الحركات المتكررة:** أول إطار وآخر إطار متطابقين عشان ما تبان قفزة.
- **العصا:** معه في كل الحركات، إلا إذا كانت الحركة تحتاج يدين.

## ٨. قبل ما ترسل الملف

1. افتحه في أي عارض GLB، وتأكد إن الخامات طالعة والحركات تشتغل.
2. أرسله لي، وأنا أفحصه بالأداة `tools/art/check_asset.py`. تطلع لي المثلثات والخامات والعظام والحركات والحجم والاتجاه.
3. بعدها أركّبه وأرسل لك صور من داخل اللعبة.

**أدوات تقدر تستخدمها:**
- **Blender:** مجاني.
- **Mixamo:** للهيكل والحركات تلقائياً، ومجاني.
- **Meshy أو Tripo:** لتوليد الموديل.
- **أي برنامج ثاني:** المهم الملف النهائي GLB بالمواصفات اللي فوق.
