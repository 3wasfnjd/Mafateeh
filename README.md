# مفاتيح — Mafateeh

لعبة ألغاز لطيفة من **عبودين قيمز — Aboden Games**، تستكشف فيها غرفًا ودهاليز وتحل ألغازًا متدرجة الصعوبة لفتح الطريق إلى المرحلة التالية. تضم 21 مرحلة، منها ألغاز بطابقين.

## التراخيص

اللعبة مفتوحة المصدر بترخيص [MIT](LICENSE): يمكنك استخدامها وتعديلها وتوزيعها وبيعها، مع الاحتفاظ بإشعار الحقوق باسم **عبودين قيمز — Aboden Games** ونص الترخيص.

مكتبة Three.js تحت [ترخيص MIT الخاص بها](licenses/THREE-LICENSE.txt)، مع حفظ حقوق مؤلفيها.
