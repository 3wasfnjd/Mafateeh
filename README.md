# مفاتيح — Mafateeh

لعبة ألغاز لطيفة من **عبودين قيمز — Aboden Games**: تقود شخصية سعودية صغيرة بثوبها وشماغها وعقالها عبر أفنية وغرف ودهاليز وبيوت من طابقين مستوحاة من الدرعية والعمارة النجدية. تحرّك الصناديق، وتحمل الطوب والأوزان، وتوجّه الضوء بالمرايا، وتفتح الأبواب والجسور لتصل إلى مخرج كل مرحلة. تضم 21 مرحلة.

اللعبة متاحة بنسختين:

- **نسخة Meta Quest الأصلية** (الواقع الافتراضي والواقع المختلط) في مجلد `quest-native/`.
- **نسخة الويب** المرجعية في جذر المستودع.

التوثيق التقني (البناء والتثبيت) في مجلد [`docs/`](docs/).
