# مفاتيح — Mafateeh

لعبة ألغاز ثلاثية الأبعاد تضم 21 مرحلة: غرف ودهاليز، مفاتيح، صناديق، مرايا، تروس، موازين، طابقين، ومسبح مصغّر مع طوبة قابلة للحمل.

## التشغيل

- نسخة الويب تعمل باللمس أو الفأرة، مع اختيار مؤقت لجميع المراحل.
- يدعم الكود WebXR لوضعي VR وAR على متصفح نظارة متوافق؛ تظهر أزرار الدخول بعد فحص الدعم.
- AR يتطلب تتبّع سطح حقيقي. جميع المجسمات والخامات والأصوات مولّدة محليًا دون تحميل أصول خارجية.
- للتطوير: `npm run serve` ثم `http://localhost:8080`. للنظارة استخدم رابط HTTPS.
- للاختبارات: `npm test`، دون تثبيت حزم. اختبارات XR تستخدم بيئة محاكاة برمجية؛ لم يتم التحقق على نظارة فعلية.

## الملفات والتراخيص

`src/game.js` اللعبة والمراحل والأصول الإجرائية، و`src/xr.js` تكامل النظارة، و`vendor/three.module.js` نسخة Three.js r170 المحلية. إعداد GitHub Pages موجود في `.github/workflows/pages.yml`.

Three.js تحت ترخيص MIT المرفق في `licenses/THREE-LICENSE.txt`. لم يُحدَّد ترخيص إعادة توزيع مستقل لكود اللعبة الأصلي. تفاصيل التحكم والتحقق في `docs/quest.md`.
